## 2024-05-19 - Keyboard Accessibility Focus Indicator
**Learning:** Adding `:focus-visible` pseudo-class for keyboard focus rings is a critical part of a11y, which prevents focus rings from showing up unnecessarily during mouse/touch interactions while ensuring keyboard users have a visible indicator.
**Action:** Use `:focus-visible` to add accessible focus rings to interactive elements instead of relying only on `:focus` or missing focus outlines entirely.
