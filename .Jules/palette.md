## 2024-05-24 - Accessibility Enhancements for Dynamic Content & Dark Themes
**Learning:** When dynamically generating HTML elements that use `aria-label`, ensure the label string is conditionally formatted to match any conditional visual text logic (e.g. 'Access Tool' vs 'No Link Available'). Because `aria-label` completely overrides inner text for screen readers, static or unconditional aria-labels can cause major accessibility regressions. Also, interactive elements in custom dark themes need explicit `:focus-visible` styles to maintain keyboard navigation accessibility, as default browser focus rings are often overridden or invisible against dark backgrounds.
**Action:** When implementing dynamically rendered links or buttons, conditionally assign `aria-label`s based on state, and implement `:focus-visible` for links and buttons to ensure visual clarity during keyboard navigation.
