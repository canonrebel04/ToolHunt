## 2024-06-09 - Accessibility of Conditional Dynamic Content & Focus Styles
**Learning:** Dynamically generated `aria-label` attributes must match the conditional visual text logic (e.g., "Access Tool" vs "No Link Available"). A static `aria-label` on dynamic conditional elements will override the visual text with misleading information for screen readers. Furthermore, interactive elements on dark themes often have their default focus rings suppressed or made invisible by contrast, rendering keyboard navigation extremely difficult without explicit `:focus-visible` styles with outline-offset.
**Action:** When dynamically generating HTML strings with conditional content (like JS template literals), ensure the `aria-label` logic directly mirrors the visual text conditionally. Always include explicit, high-contrast `:focus-visible` rules for custom dark-mode UI elements (`a`, `button`, `input`, `select`).
