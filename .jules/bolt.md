## 2024-07-04 - Caching List Indexes and Global Variable Caveats
**Learning:** Using `list.index()` inside a loop over queries creates an O(N*M) bottleneck. Replacing it with a dictionary lookup is O(1). However, when adding this dictionary as a module-level cache and populating it inside a function (like `_load_tools`), omitting it from the `global` statement causes Python to silently create a local variable instead, leading to runtime errors when accessed later.
**Action:** Always include newly introduced module-level cache dictionaries in the `global` statement before populating them, and prefer a standard `for idx, val in enumerate(items)` loop with an `if val not in mapping` check to preserve the first occurrence efficiently instead of `reversed(list(enumerate(items)))`.
