## 2024-06-02 - Fast-path List Lookup Optimization
**Learning:** Found a specific performance bottleneck where O(N^2) loops can be reduced to O(M) lookup times using `descriptions_map` alongside global reference checks (`primary_list is _descriptions`). Creating dynamic dicts is slower than the C implementation of `list.index()`, but caching the dictionary and using a global reference variable provides an O(1) fast-path optimization.
**Action:** Always verify if expensive O(N) internal list operations on large datasets are being called inside loops. Pre-compute hash maps for O(1) dictionary lookups to drastically lower processing time. Use Python's fast object-identity check `is` to narrow down optimization applicability to the targeted variables without sacrificing fallback code handling.
