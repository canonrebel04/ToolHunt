## 2024-05-24 - Optimize array lookups for static module-level datasets
**Learning:** Using `find_indices` with `.index()` scan does an expensive O(N) lookup. When querying many values against a large but static module-level dataset, this approach creates an implicit O(N*M) bottleneck.
**Action:** When working with static datasets that are lazy-loaded once at module scope (like `_descriptions`), pre-compute a lookup hash map (e.g. `_descriptions_map`) alongside the initial load. Use Python's fast object identity comparison (`is`) in generic functions like `find_indices(primary_list, query)` to check if the target list is the static dataset, falling back to the O(1) hash map if true. This avoids slowing down small dynamic lists while vastly speeding up large static queries.
