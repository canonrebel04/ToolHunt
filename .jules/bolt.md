## 2024-05-31 - Fast path dictionary lookup optimization
**Learning:** Found an O(n^2) list lookup bottleneck (`list.index()`) being used iteratively against the large (2860-element) static module-level descriptions dataset in ToolHunt's main search execution path. A dictionary mapping strings to indices generated upon DB load gives huge gains. Using `primary_list is _descriptions` inside `find_indices` provides a reliable, fast path specifically targeting the cached list while preserving original signature and logic for non-cached lists.
**Action:** When working with statically loaded module-level arrays where items need to be looked up by value frequently, cache a dictionary mapping values to array indices at load time. Use `is` to quickly branch to the optimized hash map logic.
