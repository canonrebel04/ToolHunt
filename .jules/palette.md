## 2024-08-02 - Keyboard focus indicators without compromising mouse aesthetics
**Learning:** Adding a global `:focus-visible` outline is a highly effective way to improve keyboard accessibility in web applications. Mouse users won't see the focus ring on buttons and links, avoiding visual clutter, while keyboard users gain clear visual feedback.
**Action:** Always implement `:focus-visible` globally for interactive elements (buttons, links, inputs) to ensure accessibility by default.
