## 2024-03-22 - Disabled Links Accessibility
**Learning:** In the ToolHunt frontend, disabled tools in the search results correctly use CSS (`opacity: 0.5; pointer-events: none;`) to look unclickable, but they still have an `href` attribute. This makes them keyboard focusable and read as normal links by screen readers, causing unexpected behavior if activated via keyboard.
**Action:** When disabling links (instead of buttons), conditionally omit the `href` attribute entirely, append `aria-disabled="true"`, and use `tabindex="-1"` to fully remove them from the focus order while maintaining their semantic meaning. Adding a `title` tooltip also provides visual context for mouse users.
