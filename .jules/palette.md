## 2024-05-24 - Accessibility improvements for dark theme and dynamic links\n**Learning:** Default browser focus rings are invisible in this dark theme, requiring explicit `:focus-visible` styles to maintain keyboard navigation accessibility. Furthermore, dynamically generated HTML elements that use `aria-label` must ensure the label string is conditionally formatted to match any conditional visual text logic (e.g., "Access Tool" vs "No Link Available") to avoid major accessibility regressions where screen readers hear one thing and sighted users see another. \n**Action:** Always add explicit `:focus-visible` styles to interactive elements in dark-themed applications. Always ensure dynamically generated `aria-label`s reflect the actual conditional text/state of the element they describe.
