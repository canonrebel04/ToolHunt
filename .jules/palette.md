## 2025-05-18 - Improve Keyboard Navigation Accessibility with :focus-visible
**Learning:** Found that most interactive elements (buttons, links, `.example-tag`, `.fallback-category-tile`, `.retry-btn`, `.load-more`) lacked customized focus indicators, falling back to default browser outlines or using `.search-box input:focus` instead of `:focus-visible`. This creates a subpar experience for keyboard-only users who need clear, intentional focus rings, but relying on `:focus` makes focus rings appear unnecessarily for mouse users.
**Action:** Always implement `:focus-visible` globally for all interactive elements in CSS using the application's primary color variables, and suppress the default `:focus` outline. This ensures a clean UI for mouse/touch users while maintaining strong accessibility for keyboard navigation.
